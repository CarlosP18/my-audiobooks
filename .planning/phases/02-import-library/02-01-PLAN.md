## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| iOS file picker → app | Untrusted input crosses here. The user (or the OS picker) can hand the app any file of any type or size; nothing upstream validates it. |
| app → IndexedDB (`lib/db.ts`) | The only persistence tier. Everything written here is durable, on-device, and unencrypted at rest. |
| Service worker Cache Storage ↔ IndexedDB | An architectural boundary, not a network one. Phase 1 established Cache Storage as app-shell-only; audio bytes must never cross into it. |
| npm registry → build | Supply-chain boundary — the only network dependency in the entire phase. |
