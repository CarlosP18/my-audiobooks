**This plan's slice:** every import now reports honestly — the library shows work in flight while a file is copying, and says exactly what went wrong when one fails.

Output: a typed failure surface in `lib/import.ts`, `components/import-error-banner.tsx`, `components/import-placeholder-row.tsx`, and the per-file orchestration in `app/page.tsx`.
</objective>
