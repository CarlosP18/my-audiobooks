## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| deployed origin → device browser | The app shell crosses here over the public internet. HTTPS integrity is what makes service-worker registration and Add to Home Screen possible at all. |
| network response → Cache Storage | The service worker decides what is persisted on the device and replayed on later navigations. Anything it caches is served again without a network check. |
| Cache Storage ↔ IndexedDB | The architectural boundary between the app shell (Cache Storage, ~50MB on iOS) and user data (IndexedDB, from Phase 2). Untrusted input does not cross it; a misplaced caching rule does. |
