## Pattern Assignments

### `app/manifest.ts` (config, request-response)

**No analog — build to spec.** Use Next.js App Router's native `MetadataRoute.Manifest` return type.

Required fields (from UI-SPEC.md "Icon & Splash Direction" + PITFALLS.md Pitfall 1):
```typescript
import type { MetadataRoute } from 'next'

export default function manifest(): MetadataRoute.Manifest {
  return {
    name: 'My Audiobooks',
    short_name: 'My Audiobooks',
    display: 'standalone',
    background_color: '#0A0A0A', // Dominant token
    theme_color: '#0A0A0A',      // Dominant token
    icons: [
      { src: '/icon?size=192', sizes: '192x192', type: 'image/png', purpose: 'any' },
      { src: '/icon?size=512', sizes: '512x512', type: 'image/png', purpose: 'any' },
      { src: '/icon?size=512', sizes: '512x512', type: 'image/png', purpose: 'maskable' },
    ],
  }
}
```
Note: `manifest.ts` icons alone are **insufficient on iOS** — the `apple-touch-icon` link tag in `app/layout.tsx` metadata is mandatory (PITFALLS.md Pitfall 1, STACK.md Version Compatibility table).

### `app/icon.tsx` (component, transform)

**No analog — build to spec.** Uses Next.js App Router's native icon convention with `ImageResponse` from `next/og`.

Spec (UI-SPEC.md "Icon & Splash Direction"):
- Glyph: single flat-color merged SVG path combining open-book silhouette + 3-4 vertical audio-wave bars. No gradients, no photographic elements, no drop shadows.
- Foreground (glyph) color: `#F5F5F5`
- Background fill: `#171717` (opaque, solid — not `transparent`)
- Safe area: glyph centered within ~70% of canvas (keep ~15% margin from edges)
- Sizes needed: 192×192 and 512×512 (referenced by `app/manifest.ts`)

```typescript
import { ImageResponse } from 'next/og'

export const size = { width: 512, height: 512 }
export const contentType = 'image/png'

export default function Icon() {
  return new ImageResponse(
    (
      <div style={{
        width: '100%', height: '100%',
        background: '#171717',
        display: 'flex', alignItems: 'center', justifyContent: 'center',
      }}>
        {/* book + audio-wave glyph SVG, foreground #F5F5F5, ~70% safe area */}
      </div>
    ),
    { ...size }
  )
}
```

### `app/apple-icon.tsx` or `public/apple-touch-icon.png` (component/asset, transform/file-I/O)

**No analog — build to spec.** Critical per PITFALLS.md Pitfall 1 (iOS ignores manifest icons entirely; only the `apple-touch-icon` link matters).

Required constraints:
- Exactly 180×180px
- **Fully opaque background — no transparency.** iOS renders transparent pixels as black.
- Same glyph/color spec as `app/icon.tsx` (`#F5F5F5` on `#171717`)
- If using `app/apple-icon.tsx`, Next.js auto-generates the `<link rel="apple-touch-icon">` tag. If pre-rendering to `public/apple-touch-icon.png` instead, the link tag must be added manually in `app/layout.tsx` metadata (see below).

### `app/layout.tsx` (root layout, request-response)

**No analog — build to spec.** Combines Next.js Metadata API + PWA meta tags + Geist font wiring + safe-area padding.

Required metadata (from UI-SPEC.md + PITFALLS.md Pitfall 1):
```typescript
import type { Metadata, Viewport } from 'next'
import { Geist, Geist_Mono } from 'next/font/google'

export const metadata: Metadata = {
  title: 'My Audiobooks',
  appleWebApp: {
    capable: true,
    statusBarStyle: 'black-translucent',
    title: 'My Audiobooks',
  },
  other: {
    // explicit apple-touch-icon link if not using app/apple-icon.tsx auto-generation
  },
}

export const viewport: Viewport = {
  themeColor: '#0A0A0A',
  viewportFit: 'cover', // required for env(safe-area-inset-*) to work
}
```

Head must include (explicitly, if not covered by Next's `appleWebApp` metadata key):
- `<link rel="apple-touch-icon" href="/apple-touch-icon.png">`
- `<meta name="apple-mobile-web-app-capable" content="yes">`
- `<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">`
- `<meta name="theme-color" content="#0A0A0A">`
- `<meta name="viewport" content="viewport-fit=cover">`

Root container must apply `env(safe-area-inset-top)` padding (UI-SPEC.md Layout section) so content doesn't render under the translucent status bar. Background `#0A0A0A`, `min-h-dvh`, flex column.

Font: Geist Sans for UI text (`next/font` default from `create-next-app`), Geist Mono reserved for future numeric/timecode display (Phase 3) — both fonts should be wired into the layout even though only Geist Sans is used in Phase 1, so Phase 3 doesn't need to touch font config.

### `app/sw.ts` (Serwist service worker, event-driven + streaming)

**No analog — build to spec.** Follow `@serwist/next` getting-started conventions (STACK.md).

```typescript
import { defaultCache } from '@serwist/next/worker'
import { installSerwist } from '@serwist/sw'

declare const self: ServiceWorkerGlobalScope & { __SW_MANIFEST: any }

installSerwist({
  precacheEntries: self.__SW_MANIFEST,
  skipWaiting: true,
  clientsClaim: true,
  navigationPreload: true,
  runtimeCaching: defaultCache,
})
```

**Critical scoping rule (PITFALLS.md Pitfall 6):** precache/runtime-cache rules must target **only static app-shell assets** (JS/CSS/HTML/manifest/icons). Never route audio Blob bytes through this cache — audio storage is IndexedDB (Dexie), introduced in a later phase, and is architecturally separate from the Cache Storage API used here.

## Shared Patterns

### Dark-neutral color tokens (apply to every visual file)
**Source:** UI-SPEC.md Color section
| Token | Value | Applies to |
|-------|-------|-----------|
| Dominant | `#0A0A0A` | page background, manifest `background_color`/`theme_color`, layout `<meta theme-color>` |
| Secondary | `#171717` | icon background fill (reserved for future elevated surfaces) |
| Foreground | `#F5F5F5` | primary text, icon glyph color |
| Muted-foreground | `#A3A3A3` | secondary text, decorative glyph mark |
| Accent | `#E8B34A` | reserved — must NOT appear anywhere in Phase 1 output |
| Destructive | `#DC2626` | reserved — must NOT appear anywhere in Phase 1 output |

### iOS PWA installability checklist (apply to `app/layout.tsx`, `app/manifest.ts`, `app/apple-icon.tsx`)
**Source:** PITFALLS.md Pitfall 1
- Both `manifest.ts` icons array AND explicit `apple-touch-icon` link required — manifest alone is insufficient on iOS.
- `apple-touch-icon.png` must be exactly 180×180, fully opaque (no transparency — iOS renders transparent as black).
- `apple-mobile-web-app-capable: yes` required for standalone (no Safari address bar) launch.
- `viewport-fit=cover` + `env(safe-area-inset-top)` required together — declaring one without the other leaves content either clipped or misaligned under the status bar.

### Cache Storage vs IndexedDB separation (apply to `app/sw.ts`)
**Source:** PITFALLS.md Pitfall 6
Service worker Cache Storage (~50MB quota on iOS) is exclusively for static app-shell assets. Do not introduce any audio-file caching logic in this phase's service worker — that boundary must hold even though IndexedDB/Dexie isn't wired up until a later phase.

### Typography scale (apply to `app/page.tsx`, `app/layout.tsx`)
**Source:** UI-SPEC.md Typography section
| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px | 400 | 1.5 |
| Body | 16px | 400 | 1.5 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.2 |

### Spacing scale (apply to `app/page.tsx`)
**Source:** UI-SPEC.md Spacing Scale
xs=4px, sm=8px, md=16px, lg=24px, xl=32px, 2xl=48px, 3xl=64px. Header: `lg` horizontal / `xl` top padding. Empty-state stack: `sm` gap.
